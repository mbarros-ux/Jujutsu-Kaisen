## Demo ao Vivo
[Ver projeto funcionando](https://mbarros-ux.github.io/Jujutsu-Kaisen/)

## Sobre
Site de fã dedicado ao anime Jujutsu Kaisen, desenvolvido com HTML, CSS e JavaScript puro. Este foi um dos meus primeiros projetos web, criado para praticar desenvolvimento front-end com múltiplas páginas, navegação entre seções e design temático.

O site apresenta informações sobre o anime, personagens principais, episódios e formulário de contato, com uma interface inspirada na estética da série.

## Tecnologias Utilizadas
- HTML5 - Estrutura semântica de múltiplas páginas
- CSS3 - Estilização temática e layout responsivo
- JavaScript - Interatividade e manipulação do DOM

## Funcionalidades
- Site multi-página (Home, Personagens, Episódios, Contato)
- Navegação entre páginas
- Design temático inspirado no anime
- Layout responsivo (adapta-se a diferentes tamanhos de tela)
- Formulário de contato
- Interface visual atraente com cores e elementos temáticos

## Estrutura do Projeto
```
Jujutsu-Kaisen/
├── index.html          # Página inicial
├── home.html           # Home
├── personas.html       # Página de personagens
├── episodes.html       # Página de episódios
├── contact.html        # Página de contato
── home.css            # Estilos da home
├── personas.css        # Estilos de personagens
├── episodes.css        # Estilos de episódios
├── contact.css         # Estilos de contato
├── home.js             # JavaScript da home
├── personas.js         # JavaScript de personagens
├── episodes.js         # JavaScript de episódios
└── contact.js          # JavaScript de contato
```

## Como Executar

1. Clone este repositório:
```bash
git clone https://github.com/mbarros-ux/Jujutsu-Kaisen.git
```

2. Abra o arquivo `index.html` em seu navegador.
